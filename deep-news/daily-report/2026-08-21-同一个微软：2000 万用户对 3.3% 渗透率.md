懒人包：同一个微软，GitHub Copilot 用户破 2000 万，大家愿意每月自掏 10 美元。M365 Copilot 在 4.5 亿商业用户里付费渗透率只有 3.3%。两边明明是同代模型，差别只在账本方向。昨天鸭哥发了 3 篇 AI 文章。另外两篇也重要，一篇指出，识破漂亮的技术叙事要查时间戳，看有没有真实机制。另一篇认为手机 Agent 的卡点在执行环境，因为平台封死子进程和代码执行。而 APUS 开源的 PhoneBuddySDK 用五道边界给出了进程内解法。

---------------------
两份 Copilot 成绩单，差在账本方向
---------------------

同一个微软，两份成绩单放在一起对比强烈。GitHub Copilot 在 FY25 年报里用户数破 2000 万（Microsoft ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/reh8hohm638lzoi6u6/aHR0cHM6Ly93d3cubWljcm9zb2Z0LmNvbS9pbnZlc3Rvci9yZXBvcnRzL2FyMjUvaW5kZXguaHRtbA== )），个人版每月 10 美元，大家先试后买，随时退订。隔年上市的 M365 Copilot 走了另一条路：只卖企业，每席每月 30 美元，还要有 E3 或 E5 订阅打底。结果在 4.5 亿商业用户里，付费渗透率只有 3.3%（Windows Latest ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/08hwh9h2l986r4tpu5/aHR0cHM6Ly93d3cud2luZG93c2xhdGVzdC5jb20vMjAyNi8wNy8wNy9taWNyb3NvZnQtMzY1LWNvcGlsb3QtYWRvcHRpb24taXMtdW5kZXItNC01LWFmdGVyLTMteWVhcnMtb25seS0xLXVzZS1pdC13ZWVrbHkteWV0LXByaWNlcy13ZW50LXVw )）。Nadella 在 2024 年 12 月就警告传统 SaaS 会崩溃。但为了保住席位费，大厂里没人能做主让核心收入下滑。

大厂在定价上定得非常保守。M365 Copilot 刚上市时要求 300 席起购，每席每月 30 美元，还要加上 57 美元的 E5 订阅。如果 AI 真的能包办半个人的工作，企业客户只要砍掉席位，省下的钱就比多付的 AI 订阅费还多。没有广告包袱的 Meta 反而能把 Business Agent 塞进 WhatsApp 和 Messenger。目前它的周活跃商家冲到了 100 万家。Adobe 当年转型云订阅，年净利润从 8.33 亿美元大跌 65% 至 2.90 亿美元才熬出头。今天的大厂往往没决心主动让收入下滑。

鸭哥在大公司做得出好 agent，为什么不敢卖？ ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/8ghqhohor246n4clu9/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2FnZW50LW1ldGVyLXRlc3QtMjAyNjA4MjEuaHRtbA== )里算过这笔账：大厂 agent 的卡点不在技术，而在于账本方向。GitHub 的 agent 用得越多，Actions 用量越大，微软赚得越多。而 M365 的 agent 干得越好，客户砍的订阅席位就越多，直接和主营收打架。所以 Google 在 2026 年 5 月关停了独立浏览器 agent Project Mariner。他们把票务预订、自动浏览和 agentic checkout 拆进 AI Mode、Chrome Auto Browse 和 Shopping。这让产品重新服从广告变现逻辑。Amazon 账本方向有利，但它把 Alexa+ 免费开放给 2 亿 Prime 会员后，主动使用率极低。2026 年 1 月转为强制推送后，嫌烦的用户只能喊 "Alexa, exit Alexa+" 退回旧版。

鸭哥在文章里给了一套判断工具，能直接套在任何大厂 agent 发布会上。它教大家怎么从报价单读懂卖家的真实算盘。现在行业出现了 Copilot Credits、Salesforce Agentforce，还有按解决一次收 0.99 美元的 Intercom Fin。这些探索都顺着账本方向在走。它们让 agent 干得越多、用量越大，商家越赚钱。

---------------
出场时最漂亮的句子，退场最难看
---------------

分析大厂动向要看账本方向，甄别技术判词则要看具体机制。在 AI 圈里，造个新词成本极低，验证机制却代价高昂。2023 年春天红极一时的 AutoGPT，短短三周就拿了 10 万个 star。但它的核心机制只是个调用 API 的 for 循环，结果社区一直在处理死循环烧 API 额度的 issue。复杂的 GraphRAG 索引一小段文本要花 15 美元。在二十个数据集的独立评测里，67 比 69 没任何压倒性优势。微软官方仓库已经挂出告示，只做维护、不再开发新功能（GitHub ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/vqh3hrhowv5972swul/aHR0cHM6Ly9naXRodWIuY29tL21pY3Jvc29mdC9ncmFwaHJhZw== )）。相反，真正厉害的 Transformer，论文 Attention is All You Need 发表当年，大家只把它当成机器翻译的改进。它的历史地位，全是靠后续交付实绩追加回来的。

手机 Agent 卡在模型之外的地方
------------------

机制再漂亮也得能落地，但手机刚好是当下最难提供执行环境的地方。手机 AI 的任务完成度之所以比电脑端差一个数量级，卡点就在执行环境。Apple 审核条款 2.5.2 禁止下载可执行代码，Google Play 也严格限制脚本解释器。这导致大家在桌面玩得飞起的自动化逻辑，到了手机上寸步难行。

各家厂商为了破局，路子也分化得厉害。初代豆包 AI 手机模拟人手点击，频繁触发微信和支付宝等风控。二代 NaviX Ultra 只能老老实实走协议授权路线（澎湃新闻 ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/dpheh0hepo39gkclu4/aHR0cHM6Ly9tLnRoZXBhcGVyLmNuL25ld3NEZXRhaWxfZm9yd2FyZF8zMzY4ODAwNQ== )）。豆包在 2026 年 8 月 17 日上线控制电脑的云端宿主路线（科技日报 ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/e0hph7h7rlx3gwf7u2/aHR0cHM6Ly93d3cuc3RkYWlseS5jb20vd2ViL2dkeHcvMjAyNi0wOC8xNy9jb250ZW50XzU2NTI0MC5odG1s )）。这直接避开了移动端本地执行的尴尬。

APUS 在 2026 年 8 月 18 日开源的 PhoneBuddySDK（GitHub ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/7qh7h8h9n6g27mi9u6/aHR0cHM6Ly9naXRodWIuY29tL0FQVVMtQUktTGFiL1Bob25lQnVkZHlTREs= )），想在平台规则之内把执行环境整个装进一个 App 进程。它用纯 Rust 编写，没有子进程。工具调用、流式输出和会话管理全在进程内跑完，符合 Apple 2.5.2 和 Google Play 规定。项目自述移植自 xAI 的 grok-build。北京公司 APUS 靠 APUS Launcher 起家，覆盖超 20 亿用户，2023 年起转型做大模型（APUS ( https://0128b587.click.kit-mail3.com/gkuqnw5lo2h5hl03d34arh8548w8lcmhd62ev/owhkhqhwq6zmv8bqur/aHR0cHM6Ly93d3cuYXB1c2FwcHMuY29tL2NuL2Fib3V0 )）。但这项目目前刚起步。

GitHub 仓库现在挂着 25 个 star、9 个 fork。代码出自单一贡献者，版本是 v0.1.2，连 issue 和 PR 都没有。鸭哥在源码中发现了 catch_unwind 缺失和重定向逐跳拦截两处疑点，目前还没有维护者回应。大伙把它当成架构设计样本看看就行，别急着上生产。
