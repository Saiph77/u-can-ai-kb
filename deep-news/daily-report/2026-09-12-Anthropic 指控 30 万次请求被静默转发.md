十天近 30 万次静默转发，输入管道毫无防线
----------------------

Anthropic 在 9 月 10 日发布的威胁情报报告里记录了一个具体场景（Anthropic ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/wnh2hghq0l90r6tlux/aHR0cHM6Ly93d3cuYW50aHJvcGljLmNvbS90aHJlYXQtaW50ZWxsaWdlbmNlLXJlcG9ydC1zZXB0ZW1iZXItMjAyNg== )）：一家被点名团队动用了 5380 个虚假账号，多数位于新加坡和日本，把国内用户的近 30 万次请求转给 Claude 旗舰模型，绝大多数流向 Opus。用户在聊天框里敲下回车，屏幕上一切如常，提示词却在海外走了一圈，套上国内模型的外壳才递回前端。Moonshot 还保存了至少部分交互记录，并搭建了思维链提取管线。

这份报告点名了七家中国公司在 2025 年 12 月至 2026 年 8 月间的非授权蒸馏行为，其中五家可计数公司在 5 至 7 月合计发起约 1.9 亿次请求（Business Insider ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/reh8hohm6o96qrb6u6/aHR0cHM6Ly93d3cuYnVzaW5lc3NpbnNpZGVyLmNvbS9jaGluYS1haS1sYWJzLW1pbGxpb25zLWRpc3RpbGxhdGlvbi1hdHRhY2tzLWFudGhyb3BpYy1jbGF1ZGUtMjAyNi05 )）。按 Anthropic 统计，Alibaba 超过 1.51 亿次，峰值每天近 300 万次；Moonshot 超过 2300 万次；DeepSeek 超过 1210 万次；智谱超过 340 万次；小米超过 40 万次。商汤的蒸馏管线包含从第三方数据商购买的用户与 Claude 交互记录，MiniMax 则通过空壳公司自建代理网络。全部数字均出自 Anthropic 单方陈述，后台日志只有它自己看得到，未经第三方独立核实；截至 9 月 13 日，七家公司均无公开直接回应；中国商务部 9 月 9 日关于蒸馏是通行做法的表态针对的是美方此前公告，并非这份报告（联合早报 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/08hwh9h2lp0lm6apu5/aHR0cHM6Ly93d3cuemFvYmFvLmNvbS5zZy9maW5hbmNlL2NoaW5hL3N0b3J5MjAyNjA5MTAtOTY1NDMyNg== )）。

请求中转暴露出的更大隐患是凭证外泄。独立研究者 Shou 宣称从中间商买到 6TB 对话数据包，内含企业 VPN、云平台密钥、GitLab 令牌与 SSH 密钥，声称足以接管多家头部机构（推文 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/8ghqhohor7ergmulu9/aHR0cHM6Ly94LmNvbS9zaG91Y2NjYy9zdGF0dXMvMjA5ODE2OTc4MjU0MTYzMTg3MQ== )），该说法目前未经独立技术核实。今年 4 月发表的学术测量《Your Agent Is Mine》测试了 428 个中转服务，其中 17 个触发安全探针，从 440 个 Codex 会话中截获 99 组凭据与约 13GB 明文流量（arXiv ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/vqh3hrhowq2wnwiwul/aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzI2MDQuMDg0MDc= )）。只要请求经过非自有通道，prompt 里的敏感信息就处于裸奔状态。

生产数据泄露并不是什么抽象概念。鸭哥在 《Anthropic 指控 30 万次请求被静默转发，被带走的是真实生产数据》 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/3ohphkh3pk6pqxupun/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3JvdXRlci1pbnB1dC1hcy1wcm9kdWN0LTIwMjYwOTE1Lmh0bWw= ) 里列出了具体的真实样本：跨国药企员工直接贴进提示词的四国基建预算表、生效中的 Telegram 机器人密钥与飞书及 Notion 集成密钥，以及某市公安局技术员在调试时输入的公民身份证号。这些内容原本只打算发给本地工具，转头却毫无遮拦地流向了外部数据库。

鸭哥在文章里把这条输入管道拆成了三本账：黑产顺着输入管道扫密钥，模型厂商拿真实数据做蒸馏，中转站把对话打包转卖。平时大家依赖的服务合同、厂商安全防御与用户知情权三层保障，重心全落在输出端，对输入层几乎毫无约束。

可靠的防护纪律只有一条：凡非自有通道，发送的每段 prompt 都要按公开材料对待；敏感凭证不走第三方中转，采购时认准不参与训练与禁止第三方共享的商业承诺，对中间层存疑时坚持直连官方接口或自建网关。输入通道里的数据流向往往缺乏透明度，而在开发工具这一端，服务商正通过另一种更自动的方式把规则注入模型上下文。

引导知识免费发布，因为它是获客通道
-----------------

Vercel 旗下的 v0 在 9 月 9 日上线 one-click integrations（Vercel Changelog ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/l2hehmhlxd5xodfgu0/aHR0cHM6Ly92ZXJjZWwuY29tL2NoYW5nZWxvZy92MC1hZGRzLW9uZS1jbGljay1pbnRlZ3JhdGlvbnMtZm9yLWVtYWlsLWF1dGgtc2VhcmNoLWFuZC1kYXRhYmFzZXM= )）：在聊天流里提到发邮件、鉴权或连接数据库，页面就会自动弹出连接卡片。点一下连接 Resend，系统不仅自动配好环境变量与 API 密钥，还会把 Resend 官方编写的 agent skill 规则文件注入模型上下文。AI 随后写出的发信代码直接采用官方推荐的 React Email 组件，避开了网上过时的样板代码。首发供应商还包括 Amazon OpenSearch、MongoDB Atlas、Algolia 与 Clerk。

厂商的使用规约不再留在文档站等人翻，它跟着凭据一起进了模型。今年各家工具都在推进这种标准化：Stripe 推出 stripe agent setup 命令行工具，自动检测并配置 Claude Code、Codex 与 Cursor 插件（Stripe Docs ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/m2h7h5h34lk4oxuluq/aHR0cHM6Ly9kb2NzLnN0cmlwZS5jb20vY2xpL2FnZW50L3NldHVw )）；Anthropic 早在 2025 年 12 月就将 Agent Skills 开放为通用规范（Anthropic ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/dpheh0hep2zpq3clu4/aHR0cHM6Ly93d3cuYW50aHJvcGljLmNvbS9uZXdzL3NraWxscw== )）；今年 8 月发布的 Agent Plugins 1.0 规范进一步统一了插件格式（agent-plugins.org ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/e0hph7h7rd9r09f7u2/aHR0cHM6Ly9hZ2VudC1wbHVnaW5zLm9yZw== )），GitHub Copilot 随后迅速跟进（GitHub Blog ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/7qh7h8h9nxvnokt9u6/aHR0cHM6Ly9naXRodWIuYmxvZy9jaGFuZ2Vsb2cvMjAyNi0wOC0xMi1hZ2VudC1wbHVnaW5zLTEtMC1pbi12cy1jb2RlLWNvcGlsb3QtY2xpLWFuZC10aGUtY29waWxvdC1hcHA= )）。核心套件、引导知识与执行工具集这三件套，正在变成开箱即用的工程标配。

截至 9 月 7 日，officialskills.sh 统计已有 56 支工程团队发布了 660 条官方技能（officialskills.sh ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/owhkhqhwq03qr6aqur/aHR0cHM6Ly9vZmZpY2lhbHNraWxscy5zaA== )）。这些 Markdown 规则本身完全公开，卖不出钱，厂商争相发布，是因为谁抢下连接时点的默认席位，谁就能把后续的调用流一路护送到自己的计费后台。模型本身不知道某家邮件或数据库服务最合适，但只要某家的指南优先进入上下文，AI 生成的代码就会默认依赖该服务，顺理成章把开发习惯转成长期的 API 账单。

自动化注入也推高了供应链的安全敞口。Snyk 扫描 3,984 个技能样本后确认了 76 个恶意载荷，涵盖凭据窃取与后门植入（Snyk ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/z2hghnhelm9l37hzu0/aHR0cHM6Ly9zbnlrLmlvL2Jsb2cvdG94aWNza2lsbHMtbWFsaWNpb3VzLWFpLWFnZW50LXNraWxscy1jbGF3aHVi )）；Zenity 则披露 skills.sh 上植入木马的 Paperclip 技能家族累计安装量超过 170 万次（Zenity Labs ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/p8heh9h4qpkqz5uru3/aHR0cHM6Ly9sYWJzLnplbml0eS5pby9wb3N0L2F0dGFja2Vycy10YXJnZXQtYWdlbnRzLXZpYS10aGUtc2tpbGwtc3VwcGx5LWNoYWlu )），该数字为累计安装量而非去重用户数。

比恶意样本更关键的分水岭，在于注入控制权是否透明。目前 v0 还没公开注入机制的具体细节，开发者无法在界面上审查每次连接到底向模型塞入了哪些指令与背景约束。

从整条协议的演进脉络到供应链防御，鸭哥在 《v0 一键集成：连接服务时，供应商的推荐用法自动进入 AI》 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6ep2n2hzhwqvx904inhrk07d/n2hohvhv7lw7nmb0ug/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3YwLW9uZS1jbGljay12ZW5kb3Itc2tpbGxzLTIwMjYwOTEyLmh0bWw= ) 里把这条链路完整捋了一遍，帮团队评估在接入这类一键集成时如何做权限隔离与内容审查。把不确定的生成任务交给供应商预设的杠杆工具集去约束，能提高输出代码的可用性，但前提是团队必须清楚模型上下文里到底载入了哪些规则。
