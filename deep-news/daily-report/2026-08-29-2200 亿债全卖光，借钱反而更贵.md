发债 2200 亿全卖光，变贵的不是信用
--------------------

今年 AI 大厂累计发债约 2200 亿美元（Reuters ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/owhkhqhwqwgp2wfqur/aHR0cHM6Ly93d3cucmV1dGVycy5jb20vbGVnYWwvdHJhbnNhY3Rpb25hbC91cy1jb3Jwb3JhdGUtYWktZGVidC1zdXJnZS10ZXN0cy1pbnZlc3Rvci1saW1pdHMtZmF0aWd1ZS1lbWVyZ2VzLTIwMjYtMDgtMjE= )），去年同期只有 125 亿美元。Amazon、Alphabet、Meta、Oracle、NVIDIA 和 SpaceX 这六家发债合计就超过了 2000 亿美元（Bloomberg ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/z2hghnhelepnqpizu0/aHR0cHM6Ly93d3cuYmxvb21iZXJnLmNvbS9uZXdzL2FydGljbGVzLzIwMjYtMDgtMDcvYWktZGVidC1pbmRpZ2VzdGlvbi1mb3JjZXMtd2FsbC1zdHJlZXQtdG8tcmV0aGluay1ib25kLXNhbGVz )）。这些债虽然全部卖光，借钱成本却在变贵。变贵的不是信用，是养老金和保险组合里那道 2% 到 3% 的单一发行人上限，一年数次的巨额发债，正在把这个额度一次次打满。

大厂的融资难度正在上升。Amazon 在 7 月发行 250 亿美元公司债，认购倍数只有 1.6 倍，是本轮周期最弱表现（Bloomberg ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/p8heh9h4q4gmnxtru3/aHR0cHM6Ly93d3cuYmxvb21iZXJnLmNvbS9uZXdzL2FydGljbGVzLzIwMjYtMDctMDcvYW1hem9uLXJldHVybnMtdG8tdXMtYm9uZC1tYXJrZXQtdG8tZnVuZC1haS1pbmZyYXN0cnVjdHVyZS1idWlsZA== )）。相比之下，他们在 3 月发行 370 亿美元债券时，认购倍数还有 3.4 倍。

NVIDIA、SpaceX 与 Amazon 各自发行的 250 亿美元新债，在上市首日全线破发。在 91 只同类大厂债里，有 78 只的收益率已经高于发行水平。发行让价中位数在一年内从 0.0225 个百分点扩大到了 0.12 个百分点。

最后开出什么价，取决于当时还有额度的边际买家愿意接多少。BlackRock 承销的 Meta 得州 El Paso 数据中心项目债，规模 125 亿美元，2048 年到期。这笔债的利差约 2.9 个百分点，是 Amazon 直接发债利差（约 1.2 个百分点）的两倍多。这个差价就是 AI 基建资金离开大公司资产负债表时必须支付的影子价格。

额度耗尽是事前发生的连续过程，走在信用违约前面，并不需要公司经营出错，只需要发债频率和规模足够快。Alphabet 已经确认年内不再发美元债，Amazon 转向加发欧元债与瑞士法郎债。同时，Broadcom 也在帮 Anthropic 等客户筹集 600 亿美元以上的债务融资（Reuters ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/x0hph6heqe9o5xtgul/aHR0cHM6Ly93d3cucmV1dGVycy5jb20vdGVjaG5vbG9neS9icm9hZGNvbS1zZWVrcy1tb3JlLXRoYW4tNjAtYmlsbGlvbi1sYXRlc3QtYWktZGVidC1kZWFsLWJsb29tYmVyZy1uZXdzLXJlcG9ydHMtMjAyNi0wOC0yMA== )）。

---------------------------
自我改进 AI 的全景矩阵：所有人停在 Level 1
---------------------------

钱的供给卡在额度上限，而研究自动化的进展，则卡在验证信号的供给上。我们可以把自我改进的 AI 玩家放进二维矩阵。纵轴是改什么，分为权重、训练代码、agent 的 harness 和评估器四个层级；横轴则是靠什么信号验证。已证实的自我改进强度，正沿着验证信号的五级梯度递减。最强的是 formal verifier 和执行反馈，接着是奖励模型与 LLM judge，最弱的是自评估。碰到任何递归自我改进的声明，得先看它靠什么信号验证。

现在大部分玩家都挤在执行反馈这一列，而自评估那一列空无一人，所有人实际上都停在 Level 1。Weco AIDE² 靠着双层循环 8 天无人值守，跑出的 harness 击败了人工调优两年的版本。但他们自测 Level 2 时，点火没有成功（Weco ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/e0hph7h7r7q686c7u2/aHR0cHM6Ly93d3cud2Vjby5haS9ibG9nL2ZpcnN0LWV2aWRlbmNlLW9mLXJlY3Vyc2l2ZS1zZWxmLWltcHJvdmVtZW50 )）。在普林斯顿的 shadow evaluation 里，Claude Opus 4.8 拿了 3000 美元预算做六天开放式研究。原作者按会议标准，直接拒绝了它产出的两篇论文（arXiv ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/7qh7h8h9n9wqrlf9u6/aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzI2MDcuMjcxOTE= )、MIT Tech Review ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/owhkhqhwqwgp2duqur/aHR0cHM6Ly93d3cudGVjaG5vbG9neXJldmlldy5jb20vMjAyNi8wOC8xOC8xMTQyMTg4L2FpLXJlY3Vyc2l2ZS1zZWxmLWltcHJvdmVtZW50Lw== )）。

钱不是问题。RSI 拿了 6.5 亿美元融资，估值达到 46.5 亿美元（FinSMEs ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/z2hghnhelepnqvhzu0/aHR0cHM6Ly93d3cuZmluc21lcy5jb20vMjAyNi8wNS9yZWN1cnNpdmUtc3VwZXJpbnRlbGxpZ2VuY2UtcmFpc2VzLTY1MG0taW4tZnVuZGluZy1hdC00LTY1LWJpbGxpb24tdmFsdWF0aW9uLmh0bWw= )）。同时，Karpathy 的 autoresearch 开源后，agent 一夜就能跑完大约 100 个实验（GitHub ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/p8heh9h4q4gmnwuru3/aHR0cHM6Ly9naXRodWIuY29tL2thcnBhdGh5L2F1dG9yZXNlYXJjaA== )）。

自我改进最缺的就是验证信号。一份覆盖 1250 篇论文的综述显示，评估器已经成了整个领域的共同瓶颈（arXiv ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/x0hph6heqe9o55igul/aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzI2MDcuMDc2NjM= )）。在 318 篇涉及自评估的论文里，有 82% 发表在 2026 年。在 SkillsBench 测试里，人类专家写的 skills 能让任务通过率提升 16.2 分。LLM 自动生成的 skills 带来的增益却是零。这种选手兼裁判的模式，极易导致信号失真。

新鲜例证也在不断出现。Anthropic 最新展示的自动化对齐研究员 AAR，用 AI 改进对齐训练（TechCrunch ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/6qheh8hl9lnzm9i9uk/aHR0cHM6Ly90ZWNoY3J1bmNoLmNvbS8yMDI2LzA4LzI4L2FuLWFudGhyb3BpYy1yZXNlYXJjaGVyLWp1c3QtZ2F2ZS11cy1hLXBlZWstYXQtc2VsZi1pbXByb3ZpbmctYWk= )）。官方称最好的 AAR 方案平均在六小时内超过资深人类的提案。它的推理成本大约每小时 4 美元，而人类研究员需要 150 美元。把它放进二维矩阵定位：它改的是对齐训练，验证靠对齐 eval，人则在环上负责定边界和审输出。

鸭哥在 自我改进 AI：一个被压扁的二维场 ( https://0128b587.click.kit-mail3.com/xmukp4gv2oh6hp42z6lt5h204gd07tnh2glkr/kkhmh6hnxn6rkoiku7/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3NlbGYtaW1wcm92aW5nLWFpLTJkLWZpZWxkLTIwMjYwODI5Lmh0bWw= ) 里分析了九位玩家的分布，并给出三问定位法。以后碰到任何自我改进的融资或突破新闻，改什么、靠什么信号验证、人在哪，三个问题就能定位它的真实坐标。
