懒人包：Thomson Reuters 两年累计投了 4000 万美元，在 open-weight 底座上训出 Thomson 1.0，自报法律域评测打赢了主流闭源模型。鸭哥昨天发了 2 篇 AI 文章，一篇算的是这笔账，另一篇则解析了 MCP 这两年的演进主线：默认调用者如何从屏幕前点审批的人，变成自带身份的云端进程。今日动态还有 Anthropic 发布的物理设备控制标准，以及 OpenAI 对 AI 驱动的网络攻击发出的预警。

-------------------------------------
Thomson Reuters 两年花 4000 万美元在开放底座上训模型
-------------------------------------

2026 年 8 月 24 日，Thomson Reuters 把在 open-weight 底座 Qwen3.6-35B-A3B 上做后训练的 Thomson 1.0 挂上了 HuggingFace（HuggingFace ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/g3hnh5hmq34395a3u9/aHR0cHM6Ly9odWdnaW5nZmFjZS5jby90aG9tc29ucmV1dGVycy9UaG9tc29uLTEuMC1TbWFsbA== )）。这家有 175 年历史的公司自述两年累计投了 4000 万美元，耗费 35,207 个 B200 GPU 小时，算下来纯算力开销也就 10 万到 20 万美元。他们自报的法律域评测得分是 75.2，高过底座的 72.7、Gemma 4-31B 的 70.5 和 Haiku 4.5 的 67.7（LawNext ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/9qhzhnhd5popwvhzu3/aHR0cHM6Ly93d3cubGF3bmV4dC5jb20vMjAyNi8wOC90aG9tc29uLXJldXRlcnMtbGF1bmNoZXMtdGhvbXNvbi1pdHMtb3duLXByb3ByaWV0YXJ5LWxsbS10cmFpbmVkLW9uLXdlc3RsYXctYW5kLXByYWN0aWNhbC1sYXctY29udGVudC5odG1s )）。

三年前 Bloomberg 走的是另一条路，在 2023 年 3 月用 363B token 的私有金融数据，从零训练出 50B 参数的 BloombergGPT（arXiv 2303.17564 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/3ohphkh3p7e7meupun/aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzIzMDMuMTc1NjQ= )）。但 Bloomberg 终端产品负责人 Wayne Barlow 在 2026 年 4 月受访时说，这模型只是研究模型，没用在任何产品里（A-Team Insight ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/n2hohvhv73z3q7u0ug/aHR0cHM6Ly9hLXRlYW1pbnNpZ2h0LmNvbS9ibG9nL2luc2lkZS1ibG9vbWJlcmdzLWFza2Itcm9hZG1hcC10aGUtZGF0YS1tb2F0LWJlaGluZC10aGUtYWk= )）。

对数据富集的垂直公司来说，这展示了一条新路：在 open-weight 底座上做私有后训练。4000 万美元预算里算力只是零头，钱主要花在专有内容资产、专家标注和评测体系上，底座权重反而退成了随时能换的零件。

不过这也有代价。域注入后通用能力会回退，AIME 从 93.3 下滑到 90.0，以至于 CoCounsel 产品必须多模型共存。同时，用开放底座的前提也在收紧：Kimi K3 规定做 MaaS 且年营收超 2000 万美元得签单独协议，MiniMax H3 对年营收超 2000 万美元的商业产品同样要求书面授权，路透社还报道阿里计划向 Qwen 大客户收取分成，只是截至发稿尚未官宣（Quartz ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/48hvhehmxr4rl7iqu7/aHR0cHM6Ly9xei5jb20vYWxpYmFiYS1xd2VuLW9wZW4tc291cmNlLXJldmVudWUtc2hhcmluZy0wODA3MjY= )）。

鸭哥在 域模型的第三条路：一个 175 年公司的 $40M 答案 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/wnh2hghq0wew7dilux/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2RvbWFpbi1tb2RlbC10aGlyZC1wYXRoLTIwMjYwODI4Lmh0bWw= ) 里写清了自研、租 API 和后训练三条路线的决策规则。文章同时梳理了 12 家企业成败分层，并提供了启动前的三项刚性前提自检清单。

MCP 的授权正在从人点审批变成机器身份
--------------------

域模型要进生产，必须调工具。但如果 agent 要在云端无人值守运行，每次都卡在浏览器点人工审批就不现实了。为此，MCP 路线图在 2026 年 8 月 22 日把 agent identity 列为五大优先级之一，要把默认调用者从屏幕前点审批的人，变成自带身份的云端进程（MCP 官方博客 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/08hwh9h2ld3dr0ipu5/aHR0cHM6Ly9ibG9nLm1vZGVsY29udGV4dHByb3RvY29sLmlvL3Bvc3RzL21jcC1yb2FkbWFwLw== )）。

这两年里，协议分四步补上了授权能力。维护者先在 2025 年 3 月引入 OAuth 2.1 框架，11 月支持机器对机器凭据，12 月提出 WIF 提案（GitHub ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/8ghqhohorlmln0ulu9/aHR0cHM6Ly9naXRodWIuY29tL21vZGVsY29udGV4dHByb3RvY29sL21vZGVsY29udGV4dHByb3RvY29sL3B1bGwvMTkzMw== )），并在 2026 年 5 月把 ID-JAG 草案更新到了 v4（IETF ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/vqh3hrhowpzprviwul/aHR0cHM6Ly9kYXRhdHJhY2tlci5pZXRmLm9yZy9kb2MvZHJhZnQtaWV0Zi1vYXV0aC1pZGVudGl0eS1hc3NlcnRpb24tYXV0aHotZ3JhbnQv )）。

安全机制一层层叠上来，协议也跟着变厚。规范把面向个人开发者的几项能力砍掉了。

像 2026 年 7 月 28 日那次变更就废弃了 Sampling 与 Roots，Logging 也一并列入弃用（MCP 官网 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/l2hehmhlx38374hgu0/aHR0cHM6Ly9tb2RlbGNvbnRleHRwcm90b2NvbC5pby9zcGVjaWZpY2F0aW9uLzIwMjYtMDctMjgvY2hhbmdlbG9n )）。其中 Sampling 从进入规范到废弃，只存在了 8 个月。

往后谁能审批、谁能撤销委托，关口都交到了签发 token 的一方手里，在 .env 里贴长命 API key 的习惯正在成为历史。现在远程部署 MCP server，其实已经能接 OAuth 2.1 和 Enterprise-Managed Authorization 扩展；不过 WIF 还只是 Draft 状态，暂时不用急着写校验代码（GitHub ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/8ghqhohorlmln0ulu9/aHR0cHM6Ly9naXRodWIuY29tL21vZGVsY29udGV4dHByb3RvY29sL21vZGVsY29udGV4dHByb3RvY29sL3B1bGwvMTkzMw== )）。要是未来两三个规范周期内，WIF 和 DPoP（RFC 9449 ( https://0128b587.click.kit-mail3.com/75u673owgkb8h6xq3x9fzhwq7lk5pcnhrk07d/dpheh0hep0l0nmflu4/aHR0cHM6Ly93d3cucmZjLWVkaXRvci5vcmcvcmZjL3JmYzk0NDk= )）还停在草案里，这个判断就失效了。
