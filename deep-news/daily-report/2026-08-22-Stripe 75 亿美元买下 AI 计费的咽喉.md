懒人包：Stripe 掏了约 75 亿美元买下年化收入约 1.4 亿美元的 OpenRouter，用约 54 倍市销率卡住了 AI 经济计费和路由的咽喉。这也是鸭哥昨天发布的 2 篇 AI 文章之一。另一篇聊了 UiPath 的反直觉动作：把收费十几年的流程开发免费送给 coding agent，改在运行时按次收钱。此外，今日的轻量进展还包括企业 token 账单失控、小模型 Faraday 在科研任务自称的成绩，以及 NVIDIA 拟获取 Poolside 模型授权的动向。

Stripe 买下的不是收入，是入口
------------------

Stripe 在 8 月 19 日官宣买下 OpenRouter（OpenRouter ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/25h2hoh3mg6p33h8u4/aHR0cHM6Ly9vcGVucm91dGVyLmFpL2Jsb2cvYW5ub3VuY2VtZW50cy9vcGVucm91dGVyLWlzLWpvaW5pbmctc3RyaXBl )），Bloomberg 在 8 月 16 日就透露了风声（Bloomberg ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/qvh8h7hdkvzmdouguk/aHR0cHM6Ly93d3cuYmxvb21iZXJnLmNvbS9uZXdzL2FydGljbGVzLzIwMjYtMDgtMTYvc3RyaXBlLW5lYXJzLWRlYWwtdG8tYnV5LWFpLWZpcm0tb3BlbnJvdXRlci1mb3Itb3Zlci03LWJpbGxpb24= )）。根据 NYT 引述知情人士的消息，最终交易金额约 75 亿美元，创始人拿走 15 亿美元（NYT ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/g3hnh5hmqnr8mpi3u9/aHR0cHM6Ly93d3cubnl0aW1lcy5jb20vMjAyNi8wOC8xOS9idXNpbmVzcy9zdHJpcGUtb3BlbnJvdXRlci1haS5odG1s )）。
OpenRouter 三个月前刚完成 1.13 亿美元的 Series B，估值 13 亿美元（TechCrunch ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/9qhzhnhd5x0vdnfzu3/aHR0cHM6Ly90ZWNoY3J1bmNoLmNvbS8yMDI2LzA4LzE2L3N0cmlwZS13aWxsLXJlcG9ydGVkbHktYWNxdWlyZS1haS1nYXRld2F5LXN0YXJ0dXAtb3BlbnJvdXRlci1mb3ItN2I= )），相当于三个月里估值跳涨约 5.7 倍。按 Sacra 估算其 7 月年化收入约 1.4 亿美元来算（Sacra ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/3ohphkh3pr053xtpun/aHR0cHM6Ly9zYWNyYS5jb20vcmVzZWFyY2gvb3BlbnJvdXRlci1ncm93aW5nLTI5LW1vbS1hdC0xNDBtLXllYXI= )），这笔交易折合市销率接近 54 倍。这也难怪 Hacker News 上的高赞评论直接把 70 亿美元拿去跟 Lyft、Dolby 以及 Alaska Airlines 的市值对比，质疑一个 API 中间商凭什么卖到这个价格。

OpenRouter 平台上汇集了 400 多种模型、1000 多万开发者，每天消耗超过 10 万亿 token（OpenRouter ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/25h2hoh3mg6p33h8u4/aHR0cHM6Ly9vcGVucm91dGVyLmFpL2Jsb2cvYW5ub3VuY2VtZW50cy9vcGVucm91dGVyLWlzLWpvaW5pbmctc3RyaXBl )），主要靠收取 5.5% 的 credits 手续费变现（Payments Dive ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/n2hohvhv7gm9vms0ug/aHR0cHM6Ly93d3cucGF5bWVudHNkaXZlLmNvbS9uZXdzL3N0cmlwZS1vcGVucm91dGVyLWZpbmFsbHktc3RyaWtlLWEtZGVhbC84MjgzMjY= )）。这家公司最值钱的，就是那个不偏不倚的多模型货架入口。
Stripe 联合创始人 Patrick Collison 官宣时说，token 是构建 AI 公司的核心货币，而 Stripe Sessions 2026 的主题正好是 AI 时代的经济基础设施（Stripe ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/48hvhehmx9vdmlsqu7/aHR0cHM6Ly9zdHJpcGUuY29tL2Jsb2cvZXZlcnl0aGluZy13ZS1hbm5vdW5jZWQtYXQtc2Vzc2lvbnMtMjAyNg== )）。加上 Stripe 在 2025 年 2 月交割了对稳定币平台 Bridge 的 11 亿美元收购（CNBC ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/wnh2hghq04n2q6alux/aHR0cHM6Ly93d3cuY25iYy5jb20vMjAyNS8wMi8wNC9zdHJpcGUtY2xvc2VzLTFwb2ludDEtYmlsbGlvbi1icmlkZ2UtZGVhbC1wcmVwYXJlcy1mb3Itc3RhYmxlY29pbi1wdXNoLS5odG1s )），以及 Cloudflare 在 2026 年 8 月 4 日推出 AI agent 身份标识和可编程钱包（Cloudflare ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/reh8hohm674lmrb6u6/aHR0cHM6Ly93d3cuY2xvdWRmbGFyZS5jb20vcHJlc3MvcHJlc3MtcmVsZWFzZXMvMjAyNi9jbG91ZGZsYXJlLWdpdmVzLWFpLWFnZW50cy1hbi1pZGVudGl0eS1hbmQtYS13YWxsZXQ= )），大家都在往同一个流量和控制平面靠拢。这中间，支付清算与信贷牌照是 Stripe 拥有的制度资产。

鸭哥在从未来倒推：Stripe 为什么花 $7.5B 买 OpenRouter ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/08hwh9h2lxv626spu5/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3N0cmlwZS1vcGVucm91dGVyLTIwMjYwODIyLmh0bWw= )里拆了这笔账。以前 Stripe 只看得见 AI 客户收了多少钱，OpenRouter 只看得见客户烧了多少 token。
商户 ID 打通后，Stripe 第一次能判断一家 AI 公司的边际毛利是不是在恶化。在这套因果关系里，token 数据是领先指标，支付数据是滞后指标，这套实时经营数据可以直接接入 Stripe Capital 做小微信贷的风控。

但收购也带来了一个信任悖论。哪怕 OpenRouter 在官宣里承诺其路由决策依然只以用户利益为唯一导向（OpenRouter ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/25h2hoh3mg6p33h8u4/aHR0cHM6Ly9vcGVucm91dGVyLmFpL2Jsb2cvYW5ub3VuY2VtZW50cy9vcGVucm91dGVyLWlzLWpvaW5pbmctc3RyaXBl )），但在并入支付巨头之后，模型大厂难免担心自己的调用组合变成商业情报，开发者也担心流量和资金过度集中。
Stripe 试图用数据隔离、可审计路由和数据可导出来自证，但防火墙建得越严，两侧合流的红利就越难拿到。
你不能既要数据合流的好处，又要大家相信你不会用这些数据。

把收费十几年的工具免费送出去
--------------

就在 Stripe 花大钱买别人建好的收费站这周，UiPath 却反过来，亲手拆掉了自己建了十几年的收费站，掉头往车流更密的地方重盖一座。它们在 2026 年 8 月 19 日发布了 Maestro Flow 的 public preview，引入了全新的 .flow 格式（Yahoo Finance ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/8ghqhohor3z6omtlu9/aHR0cHM6Ly9maW5hbmNlLnlhaG9vLmNvbS90ZWNobm9sb2d5L2FpL2FydGljbGVzL3VpcGF0aC1pbnRyb2R1Y2VzLXVpcGF0aC1tYWVzdHJvLWZsb3ctMTIzMDAwOTQzLmh0bWw= )）。
在新架构下，无论是 Claude Code、Cursor、Copilot 还是 Codex 等外部 coding agent 写出来的流程，一个字都不用改就能直接丢进生产平台运行（PRISM ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/vqh3hrhow4l9owcwul/aHR0cHM6Ly9wcmlzbW1hcmtldHZpZXcuY29tL3VpcGF0aC1sYXVuY2hlcy1tYWVzdHJvLWZsb3ctdG8taGVscC1kZXZlbG9wZXJzLWJ1aWxkLWFuZC1nb3Zlcm4tYWktYWdlbnQtd29ya2Zsb3dz )）。以前的 RPA 生意主要靠 Studio 的人头年费、robot 的 license 授权和帮人拖流程图的顾问生态，但这座收费站正一天天变老：UiPath 截至 2026 年 4 月 30 日的 2027 财年一季度单季收入有 4.184 亿美元（同比涨了 17%），但 ARR 增速已经跌到 12% 左右，而且服务收入占比只有 3.9%（UiPath 财报 ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/m2h7h5h349v63xtluq/aHR0cHM6Ly9pci51aXBhdGguY29tL25ld3MvZGV0YWlsLzQ1Mi91aXBhdGgtcmVwb3J0cy1maXJzdC1xdWFydGVyLWZpc2NhbC0yMDI3LWZpbmFuY2lhbC1yZXN1bHRz )）。

根据鸭哥在把写流程这步免费送出去：UiPath 反直觉的一步棋 ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/dpheh0hepkv9e3alu4/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3VpcGF0aC10b2xsLXN0YXRpb24tMjAyNjA4MjIuaHRtbA== )中的解读，虽然 UiPath 官方目前尚未公布 Maestro Flow 的正式定价（PRISM ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/vqh3hrhow4l9owcwul/aHR0cHM6Ly9wcmlzbW1hcmtldHZpZXcuY29tL3VpcGF0aC1sYXVuY2hlcy1tYWVzdHJvLWZsb3ctdG8taGVscC1kZXZlbG9wZXJzLWJ1aWxkLWFuZC1nb3Zlcm4tYWktYWdlbnQtd29ya2Zsb3dz )），但从它的计费单位来看，生成流程这步并不收费（让客户自带 coding agent 订阅，另外给个免费入门层），而是改在运行侧按次收费。
UiPath 创始人 Daniel Dines 在 2026 年 3 月的电话会里说过，软件制造成本越低，负责安全治理、编排和扩展这些软件的平台就越值钱（Motley Fool ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/e0hph7h7re63q9i7u2/aHR0cHM6Ly93d3cuZm9vbC5jb20vZWFybmluZ3MvY2FsbC10cmFuc2NyaXB0cy8yMDI2LzAzLzEyL3VpcGF0aC1wYXRoLXE0LTIwMjYtZWFybmluZ3MtY2FsbC10cmFuc2NyaXB0 )）。把收费站从建造搬到运行，赌的就是未来路上的车会成倍增加。

要敢在运行端收钱，平台就必须证明自己在生产环境里能控住场。旧架构有两个痛点：要么是在等待审批时机器人白白占着 license，要么是半夜崩了没办法保存，只能从头重跑。
Maestro Flow 用了 durable execution 引擎，把每一步的结果都记录在流水日志中，遇到审批节点就存下状态并退出进程以实现零资源占用，审批一过，重放日志就能在断点位置直接续跑，崩溃恢复与回退补偿也全靠这套机制。

判断一家老牌软件公司，就看它的旧收入在 agent 时代是入口还是大路货。微软手里握着企业租户和广告位，旧收入是入口，所以只能把 AI 当成原有账本的加价项；而 UiPath 的开发者席位和顾问生态在 coding agent 普及后沦为大路货，既然旧收费站迟早要拆，自己动手拆反而顺畅。
这正好接上了鸭哥 8 月 21 日的文章大公司做得出好 agent，为什么不敢卖？ ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/7qh7h8h9n8q2wku9u6/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2FnZW50LW1ldGVyLXRlc3QtMjAyNjA4MjEuaHRtbA== )提出的问题：旧收入成为大路货时，公司才敢真正按用量收费。不过 UiPath 转型也有风险，比如 coding agent 压缩人工后，依赖人工的咨询伙伴渠道可能会萎缩。而且，公司在 3 月电话会里自报的 AI 产品年化收入接近 2 亿美元（The Globe and Mail ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/owhkhqhwqnpmg6tqur/aHR0cHM6Ly93d3cudGhlZ2xvYmVhbmRtYWlsLmNvbS9pbnZlc3RpbmcvbWFya2V0cy9zdG9ja3MvUEFUSC9wcmVzc3JlbGVhc2VzLzc0NjQ2NC91aXBhdGgtZWFybmluZ3MtY2FsbC1wcm9maXRzLXJpc2UtYXMtYWktZHJpdmVzLWdyb3d0aA== )），至今依然没有第三方验证。虽然 Automation Anywhere 在 5 月也推出了类似的编排治理框架，但外部 coding agent 的集成在博客上仍挂着 Soon（Automation Anywhere ( https://0128b587.click.kit-mail3.com/38uopr4lveakh2k7mmdurh45wzw58u7hzp4g0/z2hghnhel7n2p7izu0/aHR0cHM6Ly93d3cuYXV0b21hdGlvbmFueXdoZXJlLmNvbS9jb21wYW55L2Jsb2cvaW1hZ2luZS0yMDI2LWRhbGxhcy1haS1wcm9kdWN0LWFubm91bmNlbWVudHM= )），差的就是敢不敢把生成这步真正免费送出去。
