---------------
五个月里，三家撞出了同一台机器
---------------

9 月 8 日，Meta 发布个人 agent Muse（Meta 官方发布稿 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/z2hghnhelq69oxszu0/aHR0cHM6Ly9hYm91dC5mYi5jb20vbmV3cy8yMDI2LzA5L2ludHJvZHVjaW5nLW11c2UtcGVyc29uYWwtYWktYWdlbnQv )）。发布说明里有项关键设定：给每位用户配一台专属云电脑，agent 在系统里常驻。你合上笔记本离开，云端照常跑任务，浏览器会话和操作记录都留在那台机器上。

这个形态不是 Meta 凭空想出来的。今年 3 月 16 日，Manus 推出 My Computer，让 agent 直接操作本地桌面；4 月 30 日上线 Cloud Computer，提供全天候运行的 Ubuntu 虚拟机，分档按月收取 10 美元、30 美元与 50 美元（Manus 计费文档 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/p8heh9h4qn6k90aru3/aHR0cHM6Ly9oZWxwLm1hbnVzLmltL2VuL2FydGljbGVzLzE1MzkyMDc4LXVuZGVyc3RhbmRpbmctY2xvdWQtY29tcHV0ZXItcGxhbnMtYW5kLWJpbGxpbmc= )）。8 月 11 日，xAI 推出 Grok Bot，规定同一账号下的所有 Bot 共享一台常驻云电脑，就算删掉某个 Bot，里面的文件和登录态也都在（Grok Bot 官方 FAQ ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/x0hph6heq528nvbgul/aHR0cHM6Ly9kb2NzLnguYWkvZ3Jvay1ib3QvZmFx )）。加上刚亮相的 Muse，五个月里三家团队撞出了同一套机器形态。

写代码的 agent 通常不需要专属常驻机器。软件开发的工程状态都在代码仓库和 git 提交记录里，临时沙箱跑完任务直接销毁就行。个人生活没有类似 git 的版本控制系统，收件箱授权、网页登录态、下载文件和定时任务直接嵌在操作系统里。环境一旦重置，之前积攒的状态全归零。实际用起来，已经有 Grok Bot 用户指挥一个 Bot 对接约 40 家越南面料供应商，通过网页与邮件逐家比价谈单完成样品采购。这种活要跑好几天，中途断了登录态就全废，机器得一直在线。

机器常驻之后，收费方式跟着变了。Meta 官方发布页没写价格，但首席 AI 官 Alexandr Wang 在 9 月 8 日接受 CNBC 专访时透露，Muse 会按每月 20 美元与 100 美元分档收费。为了打消隐私顾虑，Meta 搬出了隔离环境 Muse Secure VM、Sentinel 安全 agent、凭据代持以及 Link by Stripe 一次性虚拟卡号。但 Wired 专访披露，Meta 承认工程师在技术层面其实还能访问这台 Secure VM（Wired 专访 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/6qheh8hl9mrvpmt9uk/aHR0cHM6Ly93d3cud2lyZWQuY29tL3N0b3J5L21ldGEtcmVsZWFzZXMtbXVzZS1hLXBlcnNvbmFsLWFpLWFnZW50LXdpdGgtcHJpdmFjeS1idWlsdC1pbnRvLWl0 )）。Hacker News 上那条 654 分、735 条评论的热帖里，大家最不放心的就是把数据托给大厂（Hacker News 讨论 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/kkhmh6hnxkwg8xcku7/aHR0cHM6Ly9uZXdzLnljb21iaW5hdG9yLmNvbS9pdGVtP2lkPTQ5NjE1NTM3 )）。这套托管权甚至惊动了跨国监管，据路透社 8 月 11 日报道，Meta 曾在 2025 年底斥资超 20 亿美元收购 Manus，后因监管要求拆分，并在 8 月恢复独立运营期间按要求删除了部分用户数据（路透社报道 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/58hvh7hg6rxp54c7u4/aHR0cHM6Ly93d3cucmV1dGVycy5jb20vd29ybGQvY2hpbmEvYWktc3RhcnR1cC1tYW51cy1yZXN1bWUtaW5kZXBlbmRlbnQtb3BlcmF0aW9ucy1kZWFsLXdpdGgtbWV0YS11bndpbmRzLTIwMjYtMDgtMTE= )）。

不想把隐私交给云端厂商，自托管路线确实走得通。开源社区里 OpenClaw 在 GitHub 积累了 389,422 颗星标，Hermes Agent 也有 244,433 颗星标。真论技术能力，家里一台常开的旧电脑和云端虚拟机并无鸿沟。两者的差别就在谁干活：自己搭机器，软硬件和网络维护全得自己扛；买商业服务，花钱买的就是别人替你当运维。

这场转变背后的定价逻辑就在这里：用户支付的订阅费，本质上是把整套环境运维与操作状态保管权让渡出去的代价。文章列出了评估个人 agent 架构的四个衡量问题：运行环境是否常开、机器由谁日常维护、关键凭证存放在哪，以及换一家服务商需要重建多少工作。托管权怎么归属、自建到底贵在哪，完整的推导鸭哥写在 云 agent 不新，新的是托管 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/7qh7h8h9nrlv0qc9u6/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3BlcnNvbmFsLWFnZW50LWN1c3RvZHktMjAyNjA5MTAuaHRtbA== ) 里了。

---------------
赚钱的端侧公司，都不叫端侧公司
---------------

看这个行业，发布会的声量不如厂商的动作好使。云上那篇把发布排成一列，看到巨头在争夺操作状态的保管权；端侧这篇把出货与收购排成一列，看到的则是整个品类的悄然消失。端侧 AI 迟迟找不到龙头企业，原因在于端侧本身只是一种部署方式，如今正从独立卖点溶解为底层零件。

芯片大厂正在迅速收走独立端侧软硬件创业公司的生存空间。以色列端侧芯片公司 Hailo 在 2024 年 2 月官方估值曾达 11 亿美元，据商业媒体 Calcalist 报道 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/25h2hoh3mk9r7xu8u4/aHR0cHM6Ly93d3cuY2FsY2FsaXN0ZWNoLmNvbS9jdGVjaG5ld3MvYXJ0aWNsZS9yajAwMHF6YW93eA== )，估值直接跌去过半降至不足 5 亿美元，员工也裁撤了约半数；芯片大厂 Microchip 已经在 2026 年 7 月 24 日签署收购协议，目前交易尚未交割（Microchip 收购公告 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/qvh8h7hdk9wg8xaguk/aHR0cHM6Ly9pci5taWNyb2NoaXAuY29tL25ld3MtZXZlbnRzL3ByZXNzLXJlbGVhc2VzL2RldGFpbC8xNDA2L21pY3JvY2hpcC10ZWNobm9sb2d5LXNpZ25zLWRlZmluaXRpdmUtYWdyZWVtZW50LXRvLWFjcXVpcmUtaGFpbG8= )）。与此同时，谷歌 Coral edgetpu 仓库 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/g3hnh5hmq49737s3u9/aHR0cHM6Ly9naXRodWIuY29tL2dvb2dsZS1jb3JhbC9lZGdldHB1 ) 已经设为只读归档，高通也在 2025 年 3 月完成了对开发平台 Edge Impulse ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/9qhzhnhd5owkpqhzu3/aHR0cHM6Ly93d3cuZWRnZWltcHVsc2UuY29tL2Fib3V0 ) 的收购。

上游忙着收编，消费端更是直接降温。普通消费者对端侧功能的买单意愿持续走低，SellCell 调查 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/3ohphkh3pem672cpun/aHR0cHM6Ly93d3cuc2VsbGNlbGwuY29tL2Jsb2cvaXBob25lLXZzLXNhbXN1bmctYWktc3VydmV5 ) 显示 73% 的 iPhone 用户认为现有 AI 功能价值小或没有，86.5% 的苹果用户不愿为此额外付费。CNET 调查 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/n2hohvhv7zqw3gu0ug/aHR0cHM6Ly93d3cuY25ldC5jb20vdGVjaC9tb2JpbGUvc21hcnRwaG9uZS1idXllcnMtY2FyZS1ldmVuLWxlc3MtYWJvdXQtYWktdGhhbi10aGV5LWRpZC1sYXN0LXllYXItY25ldC1zdXJ2ZXktZmluZHM= ) 也显示只有 11% 的受访者会因 AI 更换手机，比例同比下滑 7 个百分点。缺乏杀手级应用支撑，手机与 PC 厂商很难靠端侧 AI 卖出溢价。

单靠封装开源模型的初创团队也遭遇了信任危机。本地模型团队 Desert Ant Labs 在 9 月 8 日上线了 18 个本地模型，主打每平台每模型 10 万月活设备的免费额度。但在 Hacker News 拿到 484 分的热帖讨论中，社区用户指出其核心语音模型 Voz 实质上是英伟达开源模型 Parakeet TDT 0.6B v3 的移植版本，创始人随后在评论区公开承认（Hacker News 讨论 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/48hvhehmx4lzrququ7/aHR0cHM6Ly9uZXdzLnljb21iaW5hdG9yLmNvbS9pdGVtP2lkPTQ5NjI0ODIz )）。这把现实摆在了台面上：缺少底层芯片绑定与专有场景，纯模型封装很难筑起独立的技术壁垒。

端侧真正的商业兑现，藏在公众视线之外的垂直设备与工业产线里。索诺瓦旗下助听器品牌 Phonak 在 Infinio Sphere 设备中内置专用芯片运行本地降噪模型，将信噪比最高提升 10dB（Sonova 新闻稿 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/wnh2hghq0e79w3blux/aHR0cHM6Ly93d3cuc29ub3ZhLmNvbS9waG9uYWstZWxldmF0ZXMtc291bmQtcXVhbGl0eS1uZXctaW5maW5pby1wb3J0Zm9saW8taW50cm9kdWNpbmctcGFyYWRpZ20tc2hpZnQtcmVhbC10aW1lLWFp )）。扫地机制造商石头科技在 用户信任中心声明 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/reh8hohm6gd905f6u6/aHR0cHM6Ly91cy5yb2Jvcm9jay5jb20vcGFnZXMvcm9ib3JvY2stdHJ1c3QtY2VudGVy ) 中确认，所有视觉避障数据全程在机身本地处理；根据 IDC 口径统计，石头扫地机在 2025 年全年出货量达到 580 万台（石头科技公告 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/8ghqhohormdellilu9/aHR0cHM6Ly9uZXdzcm9vbS5yb2Jvcm9jay5jb20vZ2wvbmV3cy9yb2Jvcm9jay1yZXBvcnRzLTU2LTUxLXJldmVudWUtZ3Jvd3RoLWluLTIwMjUtcTEtMjAyNi1yZXZlbnVlLXVwLTIzLTMxLQ== )）。在工业质检领域，机器视觉厂商 Cognex 协助 Schneider Electric 优化产线检测，将电气制造中的视觉误剔除率从 2.13% 降至 0.03%（Cognex 客户案例 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/l2hehmhlx82536ugu0/aHR0cHM6Ly93d3cuY29nbmV4LmNvbS9lbi93aHktY29nbmV4L2N1c3RvbWVyLXN1Y2Nlc3Mtc3Rvcmllcy9zY2huZWlkZXItZWxlY3RyaWMtYWktaW5zcGVjdGlvbg== )）。

随着云端模型推理成本大幅降低，端侧技术成立的理由已经收窄为四条硬约束：毫秒级超低延迟、断网离线可用、敏感数据留在本地，以及严苛的法律合规要求。鸭哥在 端侧 AI 没有龙头，因为它正在从卖点变成零件 ( https://0128b587.click.kit-mail3.com/68uke37wv2h8h54w286tohpzv50nlt9hdelr4/owhkhqhwq29349cqur/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2VkZ2UtYWktc2VsbGluZy1wb2ludC10by1wYXJ0LTIwMjYwOTEwLmh0bWw= ) 里给出了端侧业务的三种拆分方法，并对这四条约束做了逐一推演。三种业务怎么拆、四条约束怎么排，原文里有一整套论证。
