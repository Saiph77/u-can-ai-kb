懒人包：同一个 DeepSeek V4 Flash 塞进 8 个 agent harness 跑 30 个 SaaS 任务，通过率能差 20 个百分点。鸭哥昨天一共发了 3 篇文章。除了聊跑分的这篇，还有给性价比最高的推理引擎装一双眼睛 ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/wnh2hghqedkrmpslux/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2RlZXBzZWVrLXZpc2lvbi13b3JrYXJvdW5kLTIwMjYwODE1Lmh0bWw= )介绍本地感知与云端推理分层架构。另外，GPU 之后，AI 公司在抢通电日期 ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/reh8hohmgp3qklt6u6/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2dwdS1haS1wb3dlci1jb21wZXRpdGlvbi0yMDI2MDgxNS5odG1s )则分析了电力基建对算力落地的约束。

----------------------
换个更好的 harness，为什么不解决问题
----------------------

Composio 做过一组测试，把同一个 DeepSeek V4 Flash 塞进 8 个不同的 agent harness。跑同一批 30 个 SaaS 任务，不同 harness 跑出来的成绩截然不同。Pi Agent 跑通了 20 个（通过率 66.7%），而 OpenCode 只过了 14 个（通过率 46.7%）（Composio ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/08hwh9h2349mn3bpu5/aHR0cHM6Ly9jb21wb3Npby5kZXYvY29udGVudC9iZXN0LWFnZW50LWhhcm5lc3MtZGVlcHNlZWstdjQtZmxhc2g= )）。模型没变只换了壳，通过率就差了 20 个百分点。鸭哥在同一个模型差 20 分：DeepSeek 的 harness 依赖性和合成数据的隐藏天花板 ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/8ghqhohom82gwrilu9/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3NpbXVsYXRvci1jb2xsYXBzZS1kZWVwc2Vlay1oYXJuZXNzLTIwMjYwODE1Lmh0bWw= )里拆了这笔账。跑分不单单代表模型能力，而是模型和 harness 拼在一起的综合成绩。比如官方的高分，是在只有 bash 和 str_replace_editor 的 minimal mode 极简环境里跑出来的。一旦脱离这个环境，跑分就会缩水。第三方机构 Artificial Analysis 复现 Terminal-Bench 2.1 时只测出了 79 分。这个成绩低于官方标称的 87.9 分（36kr ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/vqh3hrhoz6vnmqfwul/aHR0cHM6Ly9ldS4zNmtyLmNvbS9lbi9wLzM5MzYxODcyMjkxNDIxNTM= )）。

这种偏差在学术界有了理论解释。Stanford 等五所高校在 2026-08-12 的论文里提出了 simulator collapse 现象。在单一行为分布上训练 agent，策略会严重过拟合。这会导致策略熵从 1.9 跌到 0.4 nats，超过 85% 的 batch 分数完全趋同（arXiv ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/l2hehmhl8pnoqpagu0/aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzI2MDguMTIyNTM= )）。如果引入论文里的 Co-Training 机制，能让 held-out 成功率最高提升 14%。

由于 DeepSeek 没做自己的 harness 和订阅产品，所以拿不到真实用户的行为数据。只靠合成数据，分布宽度很快就会遇到天花板。鸭哥在同一个模型差 20 分：DeepSeek 的 harness 依赖性和合成数据的隐藏天花板 ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/8ghqhohom82gwrilu9/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL3NpbXVsYXRvci1jb2xsYXBzZS1kZWVwc2Vlay1oYXJuZXNzLTIwMjYwODE1Lmh0bWw= )中做了一个推断。他认为 harness 过拟合就是当前合成数据训练的隐藏天花板。为了突破这个限制，DeepSeek 在 2026-08-13 开源了 DSH（GitHub ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/m2h7h5h3dxqo2riluq/aHR0cHM6Ly9naXRodWIuY29tL2RlZXBzZWVrLWFpL2RlZXBzZWVrLWhhcm5lc3M= )）。

-----------
给推理引擎装上本地眼睛
-----------

虽然 DeepSeek 跑分有过拟合瓶颈，但它仍然是现在性价比极高的推理模型。唯一的问题是它的 API 还不支持图片输入。对此，鸭哥在给性价比最高的推理引擎装一双眼睛 ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/wnh2hghqedkrmpslux/aHR0cHM6Ly95YWdlLmFpL3NoYXJlL2RlZXBzZWVrLXZpc2lvbi13b3JrYXJvdW5kLTIwMjYwODE1Lmh0bWw= )中拆了一套分层架构。那就是用本地 3B 级别的边缘 VLM 做感知，再把提取的结构化文本送给云端 DeepSeek 算推理。本地感知延迟是 1.5 秒，而云端多模态至少要 3 到 5 秒。加上图片不用出设备，隐私性更好，所以即便官方以后推出多模态 API，这个架构依然成立。

鸭哥用自家车库摄像头的 280 张图片跑了一次零样本实测（HuggingFace ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/dpheh0helxoqvzslu4/aHR0cHM6Ly9odWdnaW5nZmFjZS5jby9MaXF1aWRBSS9MRk0yLjUtVkwtM0I= )）。他用 Liquid AI 在 2026-08-12 发布的 LFM2.5-VL-3B 模型来判断车库门开关。实测的准确率达到了 94.3%，和专门训练的小模型只差 3 到 5 个百分点（Liquid AI ( https://0128b587.click.kit-mail3.com/qdu78qpovka7h4l48v8ulh8n8ozq7h4hkzpvg/e0hph7h78zlk6pu7u2/aHR0cHM6Ly93d3cubGlxdWlkLmFpL2Jsb2cvbGZtMi01LXZsLTNi )）。但如果把任务换成 13 类物体的精细检测，召回率就掉到了 66.2%。看来轻量 VLM 跑二分类判断足够，但还没办法做精细定位和复杂检测。

这套分层架构算下来也非常划算。目前的 V4-Flash API 定价是输入每百万 token 收 $0.14，输出收 $0.28。这比 Claude Opus 5 便宜了大约 36 倍。配合零边际成本的本地感知模型，用极低成本就能搭起多模态应用。
