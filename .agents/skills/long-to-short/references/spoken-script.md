# 口播稿：要重录，可以改写

产出物是一份能对着念的稿子。读者是要录制的那个人。判断标准只有一个：**他念出来像他自己在说话，不像在读稿。**

先确认一遍：用户手上真的没有可用素材吗？如果有，你应该去做剪辑单，不是这个。改写出来的稿子在有素材的场景里是废纸——他没说过那些话。

## 这里的规则和剪辑单完全相反

剪辑单不许改一个字。口播稿必须改，而且要大改。

逐字稿里的口误、重复词、自我打断、指着屏幕说的话，全部要清理。他当时是即兴讲的，有大量"这个""那个""我给你们看一下"，念出来会非常怪。你的工作是把他的**意思和语气**提出来，用他会说的话重新组织。

但保留这些：

- 他特有的口头禅和句式
- 他用过的具体例子和数字（3500 篇、100 条、超量恢复）
- 他的攻击性和态度。他说"纯纯扯淡"就别改成"我不太认同"
- 第一人称。这是他在讲，不是解说员在介绍他

**不要引入他不知道的信息。** 不要为了让论证更完整而补充事实、案例、数据。他念到那句会卡住，因为那不是他的东西。

## 先测语速，再定字数

```bash
python scripts/transcript_index.py stats <逐字稿> --speaker <说话人>
```

用实测值，不要用"中文 250 字/分钟"这种通用经验。真实语速在 250 到 400 字/分钟之间，个体差异巨大。用错基准，五分钟的稿子能写成七分钟。

录制通常比即兴直播稍慢（对着稿子念反而更规整），可以在实测值上打个九折。

**估字数只数汉字**，别把 markdown 标记、标题、括注算进去。写完用脚本或者一行 python 数一遍，不要目测——目测会系统性偏低百分之十五左右。

## 结构

**开头不要背景介绍。** 从最强的判断、最大的身份反差、或者最得罪人的一句话开始。三秒钟决定观众划不划走。

如果说话人有很硬的信任状（做了十四年、写了三千五百篇、当过语文老师），把它和一个反直觉的判断绑在一起放开头。一个真的热爱写作的人说内容不值钱，比一个流量玩家说这句话重一百倍。

**中间是一条递进的线，不是几个并列的话题。** 破 → 破得更狠 → 那怎么办 → 立 → 展开 → 落地。每一段都要接住上一段。

**结尾压缩成一两个判断，不是摘要。** 好结尾的特征是：单独拿出来给没看过的人，他能感觉到背后有大量支撑但说不出具体是什么。

**别在结尾引入正文没展开过的新东西。** 结尾是编织，不是偷渡。

## 卡点句

每段结尾放一句独立成段的短句，做字幕卡点用。

**好的卡点句不是任何人说过的话。** 它是你听完一段之后自己 synthesize 出来的——说话人潜意识里在想、但没有明确表达的那层结构。如果原话里已经有这句，说明你只是在摘抄，不是在提炼。

（注意这条和剪辑单完全相反。剪辑单里的卡点句必须是原话逐字，因为有原声要对齐；口播稿是重录的，念什么就是什么。）

把所有卡点句抽出来排在一起读一遍。它们应该构成一条递进的论证，而不是几句互不相干的格言。构不成，说明结构还没理顺。

## 交付物结构

```markdown
# 口播脚本：<主题>

**正文 N 汉字 ｜ 预计 X 分 Y 秒**
语速基准取自原素材实测：N 字/分钟。折算说明。
加粗句为字幕卡点，剪辑时建议停顿约 0.5 秒。

## 开场（约 N 字 ｜ 0:00–0:26）
正文……
**卡点句**

## 一、<小标题写成导航标记，不是论文目录>（约 N 字 ｜ 0:26–1:29）
……

## 编辑说明
  这版的视角是谁在说话
  为什么这么排
  为什么开场从这里切入
  砍掉了什么、为什么
  时长调节：偏长先砍哪段（省多少秒），偏短加哪段
```

**「时长调节」很实用。** 录出来的时长几乎不会和估算完全一致。提前指出哪两三处可以砍、各能省多少秒、砍了会不会伤结构，比让他临场删要好得多。

小标题写成导航标记（"洁癖是最贵的东西"），不要写成目录条目（"第三部分：执行层面的建议"）。

## 自检

写完过一遍：

1. 有没有哪个卡点句是原话直接抄的？是就重写，你要的是提炼不是转录。
2. 卡点句连起来是不是一条递进的线？
3. 有没有哪段删掉之后文章不受影响？有就删。
4. 结尾有没有正文没铺垫过的新信息？
5. 通篇读下来，是不是同一个人在说话？有没有某几段突然变成解说员口吻？
6. 汉字数真的数过吗？
